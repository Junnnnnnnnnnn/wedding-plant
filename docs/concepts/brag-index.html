이름

닉네임 공개

"지수 · 현우" 가 그대로 보입니다. 피드는 여전히 철저히 익명이고, 두 화면의 규칙이 반대라는 것을 안내 모달이 분명히 말합니다.

A안 플랜 한 장 카드가 커플과 날짜로 시작합니다. 앱의 참여 플랜 카드를 그대로 키운 모양 — 한 장에 예산·진행·카테고리가 다 들어갑니다. 유진 · 태호 2026년 10월 3일 · D-24 3,600만 원 웹3열 · 한 화면에 6장 모바일1열 모달왼쪽 면 고정 + 카테고리 표 성격한 장씩 들여다보기 B안 숫자 벽 카드가 금액으로 시작하고, 카드 자체가 분홍 면입니다. 목록 전체가 벽이 되고 총예산이 같은 자리에 세로로 줄섭니다. 3,600만 원 유진 · 태호2026년 10월 3일 · D-24 웹4열 · 한 화면에 12장 모바일2열 모달100% 스택 막대 하나 성격훑으면서 비교 C안 어디까지 왔나 카드가 진행률로 시작합니다. 자랑거리를 금액이 아니라 "얼마나 준비했나" 로 잡고, 결혼식이 가까운 순으로 놓습니다. 81% 유진 · 태호 2026년 10월 3일 · D-24 일정 22개 중 18개 · 3,600만 원 웹2열 · 가로로 긴 카드 모바일1열 모달월별 축 + 끝낸 일 성격"우리가 늦은 건가" 에 답

세 안이 공유하는 것

토글의 자리(대시보드 예산 패널 아래), 안내 모달의 글, 왼쪽 레일에 자랑하기 추가(둘러보기 묶음, 피드 아래), 그리고 큰 모달의 크기 규칙입니다.

모달 크기 규칙

최대 1520 × 680, 남는 자리를 여백으로 쓰되 한 변 200px 을 넘지 않는다. 1920 × 1080 에서 정확히 각 변 200px 이 남습니다. 화면이 작아지면 여백이 16px 까지 줄었다가 그 아래로는 꽉 찹니다 — 폰에서는 사실상 전체 화면입니다.

탭바가 다섯 칸이 됩니다

폰의 하단 탭바는 지금 넷(홈 · 피드 · 참여 플랜 · Settings)인데 자랑이 들어가 다섯이 됩니다. "더보기" 뒤로 숨기면 새로 만든 화면을 아무도 못 찾습니다.

아직 안 정한 것

내리면 좋아요가 사라지나요? 다시 올릴 때 예전 좋아요를 이어받을지, 0 부터 다시 셀지 정해야 합니다. 이어받으면 "고칠 수 없다" 는 규칙을 우회해 내렸다 올리며 계속 고칠 수 있게 됩니다.

정렬 기본값 — A·B안은 최신, C안은 결혼식이 가까운 순으로 그렸습니다.
