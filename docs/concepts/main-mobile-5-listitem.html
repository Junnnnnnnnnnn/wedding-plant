지금과 무엇이 달라지나

같은 화면에 일정이 3개에서 6개로 는다. 지금은 카드마다 16px 안쪽 여백 + 8px 바깥 여백 + 그림자가 붙어, 세 줄짜리 정보 하나에 100px 넘게 쓴다. 플랜이 20개인 사람에게는 이 차이가 크다.
