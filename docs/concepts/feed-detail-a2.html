A안에서 바뀐 것

회색 카드의 주인공이 업체 중앙값 → 이 후기의 지출로 바뀌었고, 아래 후기 목록이 이 한 건의 본문으로 바뀌었습니다. 지도·머리글·바닥 버튼은 자리도 높이도 그대로입니다.

막대는 업체가 아니라 카테고리

"이 업체 후기들 사이에서" 가 아니라 "스드메 후기 61건 안에서" 입니다. 업체 단위로 묶으려면 placeId 집계가 필요하지만, 카테고리 중앙값·사분위는 이미 만들어 둔 findCategoryStats 가 그대로 답합니다. 표본이 적으면 이 막대를 통째로 감춥니다 — 3건으로 시세를 말하지 않는 규칙은 같습니다.

장소가 없으면 지도를 내지 않는다

오른쪽 변형입니다. 카테고리 아이콘 면으로 채워 봤다가 걷어냈습니다 — 정보가 하나도 없는데 168px 을 먹고, 무엇을 보라는 자리인지 알 수 없었습니다. 지도는 "이 후기가 어디서 있었나" 에 답하는 자리인데 장소가 없으면 그 질문 자체가 없습니다.

이 앱은 이미 그렇게 일관돼 있습니다 — 피드 카드도 장소가 없으면 장소 줄 자체를 내지 않습니다("미확인" 이라고 크게 적지 않습니다). 같은 규칙을 상세에도 적용해, 지도 블록을 통째로 빼고 금액·별점·한 줄이 그만큼 위로 올라오게 했습니다. 주소 줄도 함께 사라집니다.

금액 비공개

amount 필드 자체가 없는 경우입니다. 큰 숫자 자리에 "금액 비공개" 를 작게 넣고 아래 막대를 감춥니다 — ?? 0 으로 채워 "0원" 을 그리지 않습니다.

목록에서 누를 때는 이미 받은 항목을 그대로 넘기면 요청이 0개입니다. 상세 주소를 직접 열거나 새로고침하는 경우만 단건 조회가 필요하고, 그것도 목록 응답과 같은 모양 하나면 됩니다 — A안이 요구하던 "업체별 후기 목록 + 업체 단위 통계" 두 벌과는 무게가 다릅니다.

지도는 동적 SDK

정적 지도 이미지가 아니라 카카오 Maps SDK 입니다 — add-plen · schedule-detail 이 이미 쓰는 것이고, 로더는 app/components/useKakaoPlaces.ts 에 있습니다. 정적 지도는 호출 쿼터가 따로 붙고 확대·이동이 안 됩니다.

지도는 lat·lng 가 있을 때만 그립니다. 주소만 있고 좌표가 없는 후기는 지도 없이 주소 줄 + 카카오맵 링크만 냅니다 — 주소를 좌표로 바꾸는 지오코딩을 여기서 부르지 않습니다(후기마다 한 번씩 더 나가는 호출입니다).

개발 중에는 localhost 에서만 뜹니다. 카카오 JS 키가 도메인에 묶여 있어, LAN 주소(192.168.x.x)로 열면 지도만 빈 채로 나옵니다 — 화면이 깨진 게 아닙니다.

넓은 화면

폰 시트를 가운데 한 컬럼(최대 560px)으로 두되 지도만 전체 폭으로 펴는 편이 자연스럽습니다. 옆 컬럼은 두지 않습니다 — 채울 내용이 생기면 그때가 업체 상세(A안)를 만들 때입니다.
