A1

시트 한 장

다른 점 — 카드 8장을 없앤다

카드마다 두르던 테두리·그림자·여백을 걷고 흰 시트 한 장에 구분선 행으로 넣습니다. 입력칸도 평소엔 테두리가 없고 손이 닿을 때만 면이 뜹니다. 세로가 A보다 짧아 저장 버튼까지 한 화면에 들어옵니다.

세로 최단읽기 편함인라인 편집

얻는 것 스크롤이 사라지고 화면이 조용해집니다. 라벨 · 값이 표처럼 줄맞춰 읽힙니다.
잃는 것 단계별로 카드가 나타나던 연출을 못 씁니다. 필수 표시가 카드 강조 없이 * 하나에 걸립니다.

A2

확정 패널

다른 점 — 저장 버튼을 오른쪽으로 옮긴다

오른쪽 열을 420px 로 키우고 저장하면 남는 돈 2,449만원을 화면에서 제일 큰 글자로 둡니다. 저장 버튼도 그 아래에 붙습니다 — 값을 넣는 곳과 확정하는 곳을 갈라 놓는 흐름입니다.

예산이 주인공확정 분리누락 안내

얻는 것 저장 직전에 금액이 한 번 더 눈에 들어옵니다. 좌표 누락 같은 경고를 버튼 바로 위에 둘 수 있습니다.
잃는 것 폼을 다 채우고 시선을 오른쪽으로 옮겨야 합니다. 좁은 화면에서는 버튼이 맨 아래로 내려갑니다.

A3

보드 맥락 미리보기

다른 점 — 오른쪽에 그 달 보드를 통째로 보여준다

카드 한 장이 아니라 2027년 1월 컬럼 전체가 오른쪽에 서고, 새 카드가 1월 7일과 1월 14일 사이 제자리에 분홍 테두리로 끼어 있습니다. 나머지는 흐리게 둡니다.

맥락 유지가장 넓게 씀폼 1열

얻는 것 보드에서 넘어온 흐름이 안 끊깁니다. 날짜를 고를 때 앞뒤에 뭐가 있는지 보면서 정합니다.
